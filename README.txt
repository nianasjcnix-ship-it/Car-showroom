AUTOHUB - VS CODE ONLY WEBSITE

This version uses only HTML, CSS and JavaScript.
No XAMPP, PHP, MySQL or phpMyAdmin is required.

HOW TO RUN:
1. Extract AUTOHUB_VS_CODE.zip.
2. Open the extracted AUTOHUB_VS_CODE folder in Visual Studio Code.
3. In VS Code, open Extensions (Ctrl+Shift+X).
4. Search for "Live Server" by Ritwick Dey and install it.
5. Right-click index.html and choose "Open with Live Server".
6. Your website will open in your browser (usually http://127.0.0.1:5500).

FEATURES:
- Luxury dark theme with red highlights
- Responsive layout for mobile and laptop
- Explore and search cars
- Filter cars by brand
- Compare up to 3 cars
- Test-drive request form
- Contact form
- Browser localStorage saves comparison, booking requests and messages

IMPORTANT:
This is a front-end college project. Booking/contact entries are stored only in
the same browser using localStorage. They are NOT sent to an email or database.
If your college later requires a real database or admin login, a backend such
as PHP + MySQL or Node.js will be needed.

Images and Google Fonts load from the internet, so an internet connection helps.
